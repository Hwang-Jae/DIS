왜 ClickHouse와 React인가?

전통적인 RDBMS는 수백만 건의 검사 기록을 집계할 때 지연 시간이 발생합니다. NIS는 **ClickHouse**의 컬럼 지향 저장 방식을 채택하여 기존 대비 약 **100배 빠른** 쿼리 속도를 달성합니다. 이를 **React** 기반의 싱글 페이지 애플리케이션으로 구현하여 끊김 없는 사용자 경험을 제공합니다.

  • ✓ Docker 기반 배포로 인프라 독립성 확보
  • ✓ JSON/CSV 고속 파싱을 통한 데이터 마트 실시간 동기화
  • ✓ Data Lake 병행 구축으로 Raw Data 무결성 보존
